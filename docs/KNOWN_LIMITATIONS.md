# 已知限制

- 扫描 PNG 的自动题号识别此前实测失败；JPG照片、倾斜/模糊输入未完成独立验收。接受格式不代表全面OCR可用。优先用可提取印刷P题号的PDF。
- AI可能误读字母/负号/指数/位置，必须教师复核；当前模型真实教师标注手写集尚未完整验收。
- 模拟测试仅检验流程/协议，连接测试仅检验联通。其他旧模型结果不能冒充当前准确率。
- 参考答案/分类/难度含人工或AI处理；教师批准字段是产品状态，不是全库独立正确性证明。
- 单用户本地使用，不是公网/多租户服务。模型调用与学生隐私需接收者自行确认授权/预算。
- 不分发原作者运行环境、系统字体、钥匙串、学生原卷和旧状态；首次安装需网络。SHA校验不是版权或渗透审计。
- CI、原机器不同Python环境不等于第二台实体Mac验收，需接收者回传实物结果。
- 未由组委会认定整体合规、入围或获奖；作品介绍、视频及正式提交回执另行准备。
