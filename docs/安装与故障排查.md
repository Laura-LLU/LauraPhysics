# 安装与故障排查

[安装步骤](JUDGE_QUICKSTART.md) · [Mac部署](MAC_DEPLOYMENT.md) · [百炼配置](BAILIAN_SETUP.md)

| 现象 | 处理方法 |
|---|---|
| Python命令不存在或版本低于3.10 | 安装Python3.12；Windows用`py -3.12`检查 |
| CERTIFICATE_VERIFY_FAILED | macOS运行Python安装目录的`Install Certificates.command`，或在当前终端设置`SSL_CERT_FILE=/etc/ssl/cert.pem`后重试 |
| Git下载缓慢或HTTP/2错误 | 使用`git -c http.version=HTTP/1.1 clone https://github.com/Laura-LLU/OPBP-Bank.git`，或下载发布包 |
| 题图下载或校验失败 | 按[Mac指南](MAC_DEPLOYMENT.md#题图下载)下载资源包后用`bootstrap_assets.py --archive`安装 |
| ModuleNotFoundError | 运行`setup_environment.py --venv .venv`，启动时使用该`.venv`的Python |
| Chromium未安装 | `.venv/bin/python -m playwright install chromium`；Windows使用`.venv\Scripts\python.exe` |
| 页面打不开 | 保持启动终端运行；核对端口与错误信息，可追加`--port 8896` |
| 模型401/403/404/429 | 按[百炼故障表](BAILIAN_SETUP.md#故障定位)核对Key、空间、模型名和额度 |
| 答卷识别不到题号 | 使用保留可提取OPBP印刷题号的PDF，核对P编号是否清楚 |
| 导出排版异常 | 记录题号、页号、系统、Python版本及匿名输出样例 |

## 路径与设置

- 环境：推荐源码目录下`.venv`；自定义位置可用`LAURAPHYSICS_PYTHON`指定Python路径。
- 数据：`LAURAPHYSICS_OPEN_DATA`指定数据目录，默认在用户目录的`Library/Application Support/LauraPhysicsOpen`。
- 导出：`LAURAPHYSICS_OPEN_OUTPUT`指定输出位置。
- 模型Key：macOS系统钥匙串，Windows / Linux使用`LAURAPHYSICS_OPEN_API_KEY`。
- 网页端口：默认8895，原生窗口使用8785/8787。

提交问题时附系统、Python版本、程序版本、错误日志与匿名样例，密钥保留在本机。
