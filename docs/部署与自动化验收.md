# 部署与自动化验收

## 安装与运行

从[安装入口](../START_HERE.md)完成独立Python环境、题图和依赖安装。服务地址为 http://127.0.0.1:8895/ 。

## 验收顺序

1. `scripts/run_web.py --check`检查900题、依赖与题图。
2. 人工组卷、预览并导出学生卷和答案卷。
3. `scripts/verify_demo_samples.py --full-papers`检查三份完整答卷。
4. `scripts/run_tests.py --install --output test-results`运行自动化。
5. 配置模型，完成上传、批改、教师确认和批量导出。

使用项目虚拟环境执行这些脚本：macOS / Linux为`.venv/bin/python`，Windows为`.venv\Scripts\python.exe`。

## 便携源码包

```bash
python3 scripts/prepare_release.py --output ../release-package
```

包内`release-manifest.json`列出版本和逐文件SHA-256，包外检查JSON提供ZIP摘要。题图由安装器按`data/asset-manifest.json`下载校验，依赖由`requirements-tested.txt`安装。

## 结果记录

保留系统、Python版本、程序版本、提交、环境检查结果、`test-result.json`、JUnit、日志和匿名导出文件。模型评分另记原始输出、教师复核结果和调用用时。
