# 功能与操作图解

[安装与运行](../START_HERE.md) · [百炼配置](BAILIAN_SETUP.md) · [测试答卷](../examples/full-papers/README.md)

## 1. AI组卷

选择题库，输入主题、题型、数量、难度或时间要求，点击“生成并预览”。右侧检查题号、题型、分值、预计作答时间和试卷，确认后导出学生卷和答案卷。

```text
围绕动力学（03 Dynamics）组一份专项练习：2道选择题、2道计算大题，难度不限，按原题编号排序。
```

点击“按相同要求换一套”重新选题；进入“OPBP组卷”可继续调整。混合卷默认按预计作答时间分配：选择题50%、大题50%。

![AI组卷：输入教学要求和查看整卷预览](images/01-ai-compose.png)

## 2. OPBP组卷

按题号、关键词、Topic、二级知识点、难度或题型筛选。点击“加入作业”放入选题篮，查看答案、打开原题、调整题序或保留指定题目。先预览整卷，再导出PDF。

![OPBP组卷：搜索题目、查看原题和调整选题篮](images/03-manual-bank.png)

## 3. 我的作业

查看导出记录，打开学生卷、答案卷和文件位置。学生卷与答案卷使用同一主题前缀，例如`Dynamics_Student.pdf`和`Dynamics_Answers.pdf`。

![我的作业：导出记录和学生卷、答案卷入口](images/02-homework.png)

## 4. 上传答卷

在“AI批改”拖入或多选已作答文件，每批最多12份，每份20 MB。PDF优先保留可提取的OPBP印刷题号。点击识别，在本机匹配题号和评分表，核对后确认发送视觉模型。

![上传答卷：多选PDF并准备识别](images/04-upload.png)

## 5. 批改队列

最多3份并发，其余自动排队。左侧显示每份进度，右侧对照原卷，顶部显示总进度和预计剩余时间。

![批改队列：三份批改中，一份排队](images/05-batch-queue.png)

需要切换页面时点“暂停”，当前题保存后暂停；返回后点击继续，从已保存进度接着处理。

## 6. 教师复核

打开复核，逐题查看得分点、作答证据和失分原因。“查看答案”展开参考答案，“原卷第N页”定位对应页。教师可修改得分点，核对后勾选确认。

![教师复核：得分点、计算证据和对应原卷](images/06-teacher-review.png)

绿色表示全对、黄色表示部分正确、红色表示全错。选择题按明确字母、圈选或勾选判定，多选题核对完整选项集合；计算结果接受2或3位有效数字，按原题要求核对单位。

## 7. 批量导出

点击“确认本份并继续”进入下一份，全部确认后统一导出PDF与ZIP，并打开班级总结。

![批量导出：确认结果和统一导出入口](images/07-batch-export.png)

## 8. 原卷批注

导出PDF保留原卷，在题旁标出勾叉和分值，右侧对齐评分准则与简短说明。

![批改PDF：题旁勾叉、分值和同页评分准则](images/08-marked-paper.png)

## 9. 班级总结

按题序展示样本数、全对率、平均得分率、失分分布和常见问题，标出建议评讲题。统计使用已确认且包含该题的答卷；总结提供PDF链接，也包含在批量ZIP中。

![班级总结：逐题得分和建议评讲题](images/09-class-summary.png)
