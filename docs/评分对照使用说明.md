# 教师评分对照工具

本工具只用现有OPBP题目；录入表不是新题或虚构学生作答。模板默认30个空案例，所有教师判断初始为空，不能计算准确率。

## 准备

```bash
python3 scripts/evaluate_marking.py template --refs P001 P003 P013 P046 P269 P287 --output /本地路径/评测样本
```

输出cases.csv、teacher目录逐点JSON及空responses目录。题号为暂定，可以在新目录重新生成用户选择的6–10题。每题5种情况。development用于调试，holdout保留最终测试；不要用holdout结果反复改提示后仍称独立测试。

教师把PDF/PNG/JPG放responses，并在CSV填写相对路径。每个teacher JSON逐点填写expected为true或false、teacherNote，确认后teacherReviewed设true。permission填teacher-authored（教师自写）或authorized-anonymized（已授权并脱敏），teacherSeconds记录人工评分用时。题号、分值及评分版本不可自行更改。拆分题须用P155-1等独立编号；旧多小题的教师标签不可未经重新核对直接视为新题标签。

## 运行

```bash
python3 scripts/evaluate_marking.py run --manifest /本地路径/评测样本/cases.csv --results /本地路径/模型结果 --split development --send-to-model
python3 scripts/evaluate_marking.py report --manifest /本地路径/评测样本/cases.csv --results /本地路径/模型结果 --output /本地路径/对照报告
```

run只连接本机服务；显式send-to-model意味着把已确认可使用的作答发送至当前配置模型。没有教师标注或来源确认即停止；report可离线查看待完成项，不会发作答。默认只跑development；最终holdout单独运行。

比较最初ai-draft.json；教师确认后的改分稿不能充当AI准确率。分母包含所有教师已标注案例的应评得分点，未运行/失败/待核对均单列并不被悄悄排除；无教师标签显示待标注，不显示0%或100%。逐点一致不等于学习效果，整题总分相同不保证每个点相同。

调用耗时与返回用量保存于execution。费用需另外提供对应模型、区域、日期的实际单价或账单；缺用量/单价/重试未返回用量时不得填零。教师复核耗时需实际填写。
