# 教师评分对照

## 建立样本

```bash
python3 scripts/evaluate_marking.py template --refs P001 P003 P013 P046 P269 P287 --output ./evaluation-samples
```

生成`cases.csv`、逐题教师JSON和作答目录。将自写或获授权的PDF/PNG/JPG放到`responses`，在CSV填写相对路径。教师逐点填写`expected`、`teacherNote`，核对后设`teacherReviewed:true`；`permission`使用`teacher-authored`或`authorized-anonymized`，`teacherSeconds`记录人工评分用时。

样本分为`development`和`holdout`：前者用于调试，后者用于冻结后的独立测试。

## 运行与报告

```bash
python3 scripts/evaluate_marking.py run --manifest ./evaluation-samples/cases.csv --results ./evaluation-results --split development --send-to-model
python3 scripts/evaluate_marking.py report --manifest ./evaluation-samples/cases.csv --results ./evaluation-results --output ./evaluation-report
```

`run`通过本机服务将已确认作答发送当前配置的模型；`report`读取结果生成离线对照。最终测试将`--split`设为`holdout`。

报告比较原始`ai-draft.json`和教师标签，分别记录逐点一致、误给分、漏给分、失败及待核对。调用耗时与用量保存于`execution`；费用按对应模型、区域和实际账单填写。
